# UCC ICT Support

## ICT Services and Support

### Student ICT Support
UCC provides ICT support services to students including:
- Computer laboratory access
- Internet connectivity
- Email accounts
- Learning Management System (LMS) support
- Software installation assistance

### How to Get ICT Support
1. Visit the ICT Support office during office hours
2. Email: ict@ucc.co.tz
3. Phone: +255 22 2410 003
4. Submit a support request through the student portal

### IT Infrastructure
UCC maintains modern IT infrastructure including:
- High-speed internet connectivity
- Computer laboratories with latest software
- Wireless network (Wi-Fi) across campus
- Servers and data centres

### Software Services
UCC provides various software services to students and staff including:
- Licensed software for academic use
- Operating systems (Windows, Linux)
- Programming tools and IDEs
- Office productivity suites

### Professional Training in ICT
UCC offers professional ICT training courses including:
- Software Development
- Network Administration
- Cybersecurity Fundamentals
- Database Administration
- Cloud Computing

For detailed ICT support information, contact the UCC ICT office directly.
