# UCC IT Infrastructure

## IT Infrastructure Services

UCC maintains and supports modern IT infrastructure for the university community.

### Network Infrastructure
- Campus-wide wired and wireless network
- High-speed internet connectivity
- Network security and monitoring

### Data Centre Services
- Server hosting
- Data storage and backup
- Cloud services

### Hardware and Software
- Computer laboratories with modern hardware
- Licensed software for academic use
- Technical support and maintenance

### Research Infrastructure
UCC provides computing resources to support research activities.

For infrastructure-related enquiries, contact the UCC ICT office.
